# Muelle 03

FPS de un solo nivel en three.js r128. El escenario, las texturas y el audio son procedurales; el único asset externo es `soldado.glb`, el modelo animado de los enemigos.

Un muelle de noche y con lluvia; hay que aguantar tres oleadas de un equipo de asalto.

## Jugar

Publicarlo con GitHub Pages o servir la carpeta con cualquier servidor web (`index.html` y `soldado.glb` juntos). Abierto directamente como archivo local, el modelo no carga y se usan soldados simplificados.

- Escritorio: WASD, ratón, clic para disparar, clic derecho para la mira, R recarga, Espacio salta, Mayús corre.
- Móvil: pulgar izquierdo para moverse, derecho para mirar, botones de fuego, salto y recarga. Mejor en horizontal.

Necesita conexión a internet la primera vez: carga three.js desde cdnjs y jsDelivr.
